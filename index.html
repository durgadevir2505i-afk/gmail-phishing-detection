PhishGuard AI

AI-based Gmail phishing detection system designed to help users identify potentially harmful and suspicious emails.

PhishGuard AI analyzes email content using Machine Learning techniques and provides a risk level to help users recognize possible phishing messages.

How it works

Sign in with Google, select an email, and let the system analyze its content for potential phishing indicators.
