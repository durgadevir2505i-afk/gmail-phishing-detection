Privacy Policy – PhishGuard AI

Last updated: September 27, 2026

PhishGuard AI is an AI-based Gmail phishing detection system. This Privacy Policy explains what information the application accesses, why it is accessed, and how it is handled when a user connects a Gmail account.

1. Information We Access

With the user's permission, PhishGuard AI uses the Gmail API with read-only access to retrieve email information required for phishing analysis. This may include the sender, subject, date, email snippet, and email message content.

2. How We Use Gmail Information

Gmail information is used to analyze the selected email for potential phishing indicators. The system uses Machine Learning and rule-based checks to generate a risk score and classification such as Safe, Suspicious, or Phishing.

3. Gmail Permissions

The application requests the Gmail read-only permission (gmail.readonly). This permission is used only to read email information required for the detection process.

PhishGuard AI does not send, delete, modify, or manage emails on behalf of the user.

4. Authentication

Users authenticate through Google OAuth. The application does not request or store the user's Google password.

5. Data Storage and Retention

Email information retrieved through the Gmail API is used for the requested analysis. The application is not intended to permanently store users' Gmail messages or email content as a separate email database.

Authentication information required for the active session may be maintained while the user is using the application.

6. Third-Party Services

PhishGuard AI uses Google OAuth and the Gmail API to authenticate users and access Gmail information with the permissions granted by the user.

7. User Control and Revoking Access

Users can stop using the application at any time. Users can also revoke the application's Gmail access through their Google Account security and connected-app permissions.

8. Security

The application is designed to use Gmail data only for the functionality described in this policy. Users should review the permissions requested by the application before granting access.

9. Children's Privacy

This application is not specifically directed toward children. We do not knowingly request personal information from children for purposes unrelated to the application's functionality.

10. Changes to This Privacy Policy

This Privacy Policy may be updated when the application or its data practices change. Any updated version will be made available on this page.
